# fbwphlab.py
Python-based Fly-by-Wire Control model for the PH-LAB Cessna Citation II using Archimedes


## Setup Instructions 
1. Clone the repository.
## Ignore for now until (setup code is finished)
2. Open the terminal and run: `python setup_data.py`  
3. This will download the dataset into the `/data` folder.
* Do not upload data files The `.gitignore` should block them but keep your data in the `/data` folder.
